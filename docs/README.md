# Документація проєкту VetCrewEmergency

## Призначення
Документація інженерних стандартів, специфікацій та архітектурних рішень порталу швидкої допомоги тваринам `VetCrewEmergency`.

## Структура
- `adr/` — Архітектурні рішення (Architecture Decision Records).
- `specs/` — Специфікації екстреного зв'язку та функціоналу.
- `analysis/` — Звіти з продуктивності та доступності.

## Життєвий цикл документів
За правилом [DOCUMENTATION-v10](../sveltekit-canon/selection_criteria/v10/ops/DOCUMENTATION-v10.md):
- Чинні документи зберігаються як `active` в категорійних підтеках.
- Застарілі документи архівуються у `archive/`.
