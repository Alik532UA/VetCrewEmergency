# VetCrewEmergency

Сайт служби екстреної допомоги диким тваринам **Vet Crew Emergency Wildlife
Response**: гаряча лінія 24/7, бібліотека польових порад «Що робити, якщо…»,
історії порятунку, повідомлення про знайдену тварину та підтримка проєкту.

Дві мови — `uk` (типова, без префікса) і `en` (під префіксом `/en`). Мова кореня
тут не питання смаку: людина, яка щойно знайшла поранену тварину, відкриває
головну з телефона й мусить читати рідною без жодного зайвого кроку.

Зміст сайту — з матеріалів автора: структура головної, структура статті
бібліотеки (вісім блоків у незмінному порядку) і перелік тем. **Тексти дев'яти
з десяти статей складені за цими матеріалами й чекають на вичитку фахівцями** —
це поради, за якими люди діятимуть біля живої тварини.

## Чого на сайті немає

Заглушки названі заглушками навмисно, і кожна видна оком:

| Що                            | Стан                                                     |
| ----------------------------- | -------------------------------------------------------- |
| Номер гарячої лінії           | `+38 (000) 000 00 00` — у матеріалах номера немає        |
| Посилання пожертви й крамниці | кнопки не натискаються й підписані «посилання буде»      |
| Соцмережі                     | адреси `#`, значки загальні                              |
| Повні тексти історій          | сторінка показує абзац і каже, що повний текст готується |
| Знімки тварин                 | замість фотографій — емодзі виду                         |

## Запуск

⚠️ Голий `npm run dev` бере типовий порт Vite **5173**, спільний з рештою
проєктів у цій теці. Конфігурація `.claude/launch.json` цього проєкту тримає
**5195** зі `--strictPort`. Тестів це не стосується: Playwright піднімає власний
`preview` на 4173.

```
npm install
npm run dev
```
